# S.Oumar Gassama Portfolio

Crée une page d'atterrissage (landing page) moderne et épurée en une seule section avec un en-tête de héros (hero section). Inclus mon nom (S.Oumar Gassama), un sous-titre de présentation centré sur ma passion pour le développement frontend et la création d'expériences utilisateur fluides, ainsi qu'un bouton d'appel à l'action (CTA) intitulé 'Voir mes projets' où il y aura 4 projets : restaurant, boutique en ligne, portofolio et agence de voyage, avec chacun une image illustrative et une description.
